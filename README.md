# hybrid-training-tracker

A personal athletic training web app: a mobile-first tool for planning, logging, and progressing an athlete's hybrid strength, speed, power, and calisthenics program alongside Ultimate frisbee training.

Start with `CLAUDE.md` for the project's governing doc and its doc map, which routes to `PRODUCT_SPEC.md`, `TRAINING_SYSTEM.md`, `PLAN.md`, and `HANDOFF.md`.
